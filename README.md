# Praktikum Pemrograman Web I - Pertemuan 10

## Deskripsi
Project ini merupakan hasil praktikum Pemrograman Web I
yang membahas pengelolaan data menggunakan PHP dan MySQL.

## Fitur
1. Menampilkan data produk (Read).
2. Menambahkan data produk (Create).
3. Mengubah data produk (Update).
4. Menghapus data produk (Delete).

## Teknologi
- PHP
- MySQL
- XAMPP
- phpMyAdmin
- Visual Studio Code

## Struktur File
- koneksi.php
- index.php
- tambah.php
- edit.php
- hapus.php
- dokumentasi/

## Cara Menjalankan
1. Jalankan Apache dan MySQL melalui XAMPP.
2. Buat database sesuai konfigurasi pada koneksi.php.
3. Letakkan folder project di htdocs.
4. Buka browser.
5. Akses http://localhost/web1/pertemuan-10/
